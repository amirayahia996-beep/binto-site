# Binto design — الموقع

صفحة هبوط ثابتة (HTML + CSS + JS بدون أدوات بناء).

- `index.html` — المحتوى كله.
- `css/style.css` — الألوان والخطوط من نظام Binto.
- `js/main.js` — تصفية الأعمال حسب الجهة + عداد العرض (ينتهي 30 نوفمبر 2026، 11:59 مساءً بتوقيت الرياض).
- `images/` و `fonts/` — الصور وخط Tajawal.

النشر: Netlify مربوط بهذا المستودع، أي تحديث على `main` ينزل للموقع تلقائياً. إعدادات Netlify: Build command فاضي، Publish directory = `/`.
